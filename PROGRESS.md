- Added manual tag input and a **Skip** button that selects the hostname. The subscription profile title is `OBHOD <tag>`; individual VLESS links are unchanged.

On failure, publication is force-refreshed, Tailscale recreation is attempted when applicable, and checks run again with diagnostics.
